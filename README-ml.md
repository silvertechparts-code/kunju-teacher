# കുഞ്ഞു ടീച്ചർ: ഒരു രൂപ പോലും ചെലവില്ലാതെ

ഈ ഫോൾഡറിലെ എല്ലാം സൗജന്യമായി ഉപയോഗിക്കാം. ക്രെഡിറ്റ് കാർഡോ ബില്ലിങ്ങോ ഒന്നും വേണ്ട.

## 5 മിനിറ്റിൽ തുടങ്ങാൻ

1. `index.html` ഫയൽ ഫോണിലോ കമ്പ്യൂട്ടറിലോ Chrome-ൽ തുറക്കൂ. ഇത്രയും മതി ആപ്പ് പ്രവർത്തിക്കാൻ. ടീച്ചറുടെ ഉത്തരങ്ങൾ, കളികൾ, ക്ലാസ് 1 പാഠങ്ങൾ എല്ലാം ഇതിനുള്ളിൽ തന്നെയുണ്ട്. ഇന്റർനെറ്റ് വേണ്ട. `voice` ഫോൾഡർ `index.html`-ന്റെ തൊട്ടടുത്ത് ഇരിക്കണം (ZIP തുറന്നാൽ അങ്ങനെ തന്നെയാണ്). ഡബിൾ ക്ലിക്ക് ചെയ്ത് തുറന്നാലും റെക്കോർഡ് ചെയ്ത പെൺശബ്ദത്തിൽ ടീച്ചർ സംസാരിക്കും.
2. മൈക്കിൽ ചോദിക്കണമെങ്കിൽ ആപ്പ് ഒരു `https://` വിലാസത്തിൽ വേണം (ഫയലായി തുറന്നാൽ മൈക്ക് പ്രവർത്തിക്കില്ല). അതിന് താഴെ "വെബ്സൈറ്റ് ആക്കാം" കാണുക. ഇതും സൗജന്യമാണ്.

## 1. ഇത് എങ്ങനെ സൗജന്യമായി പ്രവർത്തിക്കുന്നു

| ഭാഗം | എങ്ങനെ | ചെലവ് |
|---|---|---|
| ടീച്ചറുടെ ഉത്തരം | ആപ്പിനുള്ളിൽ തന്നെ എഴുതിവെച്ച ഏകദേശം 110 വിഷയങ്ങൾ, 250-ലധികം ഇംഗ്ലീഷ്-മലയാളം വാക്കുകൾ, കൂട്ടൽ, കുറയ്ക്കൽ, ഗുണനം | ₹0, ഇന്റർനെറ്റ് വേണ്ട |
| ചോദ്യം ചോദിക്കൽ (മൈക്ക്) | ബ്രൗസറിന്റെ സ്വന്തം ശബ്ദം തിരിച്ചറിയൽ (Chrome-ൽ; Edge-ൽ വിശ്വസനീയമല്ലെന്ന് റിപ്പോർട്ടുകളുണ്ട്, ഭാഗം 3) | ₹0 |
| ടീച്ചർ സംസാരിക്കൽ | `voice` ഫോൾഡറിലെ റെക്കോർഡ് ചെയ്ത പെൺശബ്ദം: മലയാളം 2,900, ഇംഗ്ലീഷ് 2,947, ഹിന്ദി 406 വാചകം (ഭാഗം 4). അപ്പോൾ ഉണ്ടാക്കുന്ന വാചകങ്ങൾ (കണക്കിന്റെ ഉത്തരം, പുതിയ ഉത്തരങ്ങൾ) ഉപകരണത്തിന്റെ ശബ്ദത്തിൽ | ₹0 |
| വെബ്സൈറ്റ് | GitHub Pages (ഭാഗം 2) | ₹0 |
| നിങ്ങൾ അപ്‌ലോഡ് ചെയ്യുന്ന പാഠപുസ്തകം | ആപ്പ് ആ ടെക്സ്റ്റിൽ നിന്ന് ഉത്തരം തിരയും | ₹0 |

**ഭാഷകളുടെ ക്രമം:**
- **ഇംഗ്ലീഷ് പാഠങ്ങളും കണക്കും:** ആദ്യം ഇംഗ്ലീഷിൽ പറയും, പിന്നെ മലയാളത്തിൽ മനസ്സിലാക്കിത്തരും (കാർഡ്, ക്വിസ് ചോദ്യം, "ശരി!" എന്ന അഭിനന്ദനം, പാഠാവസാനത്തെ "Well done" എല്ലാം). അവയിൽ **മലയാളത്തിൽ** എന്ന ബട്ടൺ ഉണ്ട്; അത് തൊട്ടാൽ ടീച്ചർ മലയാളത്തിലെ വിശദീകരണം മാത്രം ഒന്നുകൂടി പറയും. ഉത്തര സ്ക്രീനിലും ഈ ബട്ടൺ ഉണ്ട്; "മലയാളത്തിൽ പറയൂ" എന്ന് പറഞ്ഞാലും മതി.
- **ഹിന്ദി പാഠങ്ങൾ:** ഹിന്ദി, മലയാളം, ഇംഗ്ലീഷ് എന്ന ക്രമം. **മലയാളം അക്ഷരമാല, EVS:** മലയാളം ആദ്യം, പഴയതുപോലെ.
- വലിയവർക്കുള്ള പേജിലെ ഭാഷാ നില (കൂടുതലും മലയാളം / ഇടകലർത്തി / കൂടുതലും ഇംഗ്ലീഷ്) പഴയതുപോലെ പ്രവർത്തിക്കും; "കൂടുതലും ഇംഗ്ലീഷ്" ആക്കിയാൽ ഇംഗ്ലീഷ് മാത്രം പറയും.

## എന്തുകൊണ്ട് Gemini / ChatGPT പോലുള്ള AI ഇതിൽ ഇല്ല

കുട്ടികൾക്കുള്ള ആപ്പിൽ ഇവ ഉപയോഗിക്കുന്നതിൽ നിയമപരമായ തടസ്സമുണ്ട്. Google Gemini API-യുടെ നിബന്ധനകൾ 18 വയസ്സിന് താഴെയുള്ളവരെ ലക്ഷ്യമിടുന്നതോ അവർ ഉപയോഗിക്കാൻ സാധ്യതയുള്ളതോ ആയ ആപ്പുകളിൽ അത് ഉപയോഗിക്കരുത് എന്ന് പറയുന്നു ([നിബന്ധനകൾ](https://ai.google.dev/gemini-api/terms)). അതുകൊണ്ട് ഞാൻ അത് ഒഴിവാക്കി. ഏത് AI സേവനം പിന്നീട് ചേർത്താലും, കുട്ടികളുടെ ആപ്പിൽ ഉപയോഗിക്കാൻ അവരുടെ നിബന്ധനകൾ അനുവദിക്കുന്നുണ്ടോ എന്ന് ആദ്യം വായിച്ചുനോക്കണം.

പകരം, ടീച്ചറുടെ ഉത്തരങ്ങൾ ചെറിയ കുട്ടികൾക്ക് വേണ്ടി കൈകൊണ്ട് എഴുതിയതാണ് ("Teacher Brain"). ചോദ്യം ഏത് വിഷയത്തിലാണെന്ന് ആപ്പ് മനസ്സിലാക്കി ശരിയായ ഉത്തരം പറയും. ഒരു ഉത്തരം അറിയില്ലെങ്കിൽ ടീച്ചർ ഊഹിച്ച് തെറ്റ് പറയില്ല. "ഇത് എനിക്ക് ഇപ്പോൾ അറിയില്ല, വലിയവരോട് ചോദിക്കൂ" എന്ന് പറയുകയും ആ ചോദ്യം ഓർത്തുവെക്കുകയും ചെയ്യും (ഭാഗം 6).

## 2. വെബ്സൈറ്റ് ആക്കാം (GitHub Pages, സൗജന്യം)

1. https://github.com ൽ സൗജന്യ അക്കൗണ്ട് ഉണ്ടാക്കൂ. കാർഡ് വേണ്ട.
2. മുകളിൽ വലതുവശത്തെ **+** → **New repository**. പേര് `kunju-teacher`. **Public** തിരഞ്ഞെടുത്ത് **Create repository**.
3. വരുന്ന പേജിലെ **uploading an existing file** തൊടൂ. ഈ ഫോൾഡറിലെ `index.html`, `.nojekyll`, `voice` ഫോൾഡർ എന്നിവ വലിച്ചിട്ട് **Commit changes** അമർത്തൂ. (ഒരു ഫയലിന് 25 MB-യിൽ കൂടരുത്. voice pack-ലെ ഫയലുകൾ അതിൽ താഴെയാണ്.)
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Branch `main`, folder `/ (root)`, **Save**.
5. ഒന്ന് രണ്ട് മിനിറ്റ് കഴിഞ്ഞാൽ `https://<നിങ്ങളുടെ-യൂസർനെയിം>.github.io/kunju-teacher/` എന്ന വിലാസം കിട്ടും. ഇത് ഫോണിൽ Chrome-ൽ തുറക്കൂ.
6. Chrome മെനു → **Add to Home screen**. ഇനി ഇത് ഒരു ആപ്പ് പോലെ തുറക്കും.

**വേഗത്തിൽ വേണമെങ്കിൽ:** [Cloudflare Drop](https://www.cloudflare.com/drop) (ഫോൾഡർ/ZIP വലിച്ചിടാം, 1 മണിക്കൂർ താൽക്കാലിക ലിങ്ക്, സൂക്ഷിക്കാൻ "Claim" ചെയ്ത് അക്കൗണ്ട് ഉണ്ടാക്കണം) അല്ലെങ്കിൽ [Netlify Drop](https://app.netlify.com/drop) (50 MB-ൽ താഴെ). ഇവയുടെ സൗജന്യ പരിധികൾ മാറിക്കൊണ്ടിരിക്കും, അതുകൊണ്ട് അവയുടെ വിലനിർണ്ണയ പേജ് നോക്കി ഉറപ്പാക്കൂ. GitHub Pages ആണ് ഏറ്റവും ലളിതവും സ്ഥിരവും.

## 3. ഫോണിലും കമ്പ്യൂട്ടറിലും

- **ഏറ്റവും നല്ലത്:** Android ഫോണിൽ Chrome, അല്ലെങ്കിൽ കമ്പ്യൂട്ടറിൽ Chrome. മൈക്ക് ചോദ്യങ്ങൾക്ക് Chrome ഉപയോഗിക്കൂ. Microsoft Edge-ൽ ശബ്ദം തിരിച്ചറിയൽ വിശ്വസനീയമല്ലെന്ന് Microsoft-ന്റെ സഹായ ഫോറത്തിൽ ഒരു മറുപടിയിൽ കണ്ടു; ഞാൻ അത് പരീക്ഷിച്ചിട്ടില്ല. (Edge-ൽ ടീച്ചറുടെ ശബ്ദം കേൾക്കുന്നതിന് പ്രശ്നമില്ല, മൈക്കിന്റെ കാര്യമാണ് സംശയം.)
- **iPhone/Safari:** മൈക്ക് ചോദ്യം മലയാളത്തിൽ പ്രവർത്തിക്കുമെന്ന് ഉറപ്പില്ല, ഞാൻ പരീക്ഷിച്ചിട്ടില്ല. തൊട്ട് ചോദിക്കാവുന്ന ചോദ്യങ്ങൾ എല്ലായിടത്തും പ്രവർത്തിക്കും.
- **മലയാളം ശബ്ദം:**
  - `voice` ഫോൾഡർ ഉള്ളതുകൊണ്ട് ഉപകരണത്തിൽ മലയാളം ശബ്ദം ഇല്ലെങ്കിലും ടീച്ചർ മലയാളത്തിൽ സംസാരിക്കും. Windows-ൽ Chrome-ൽ മലയാളം ശബ്ദം ഇല്ല; അതുകൊണ്ടാണ് ഇത്. (`voice` ഫോൾഡർ `index.html`-ന്റെ തൊട്ടടുത്ത് വേണം. ഫയലായി ഡബിൾ ക്ലിക്ക് ചെയ്ത് തുറന്നാലും, വെബ്‌സൈറ്റ് ആക്കിയാലും ഇത് പ്രവർത്തിക്കും.)
  - Windows-ൽ Microsoft Edge-ൽ "Sobhana / Midhun (Natural)" എന്ന സൗജന്യ മലയാളം ശബ്ദങ്ങൾ തനിയെ കിട്ടും (ഇന്റർനെറ്റ് വേണം).
  - Android-ൽ Settings → Text-to-speech → Google Speech Services-ൽ മലയാളം ഡൗൺലോഡ് ചെയ്യൂ.
  - ഏറ്റവും നല്ല ശബ്ദം തിരഞ്ഞെടുക്കാൻ ആപ്പിലെ പൂട്ട് ചിഹ്നം (വലിയവർക്ക്) → Teacher voice.
- **ഹിന്ദി ശബ്ദം (CBSE-യിലെ ഹിന്ദി പാഠങ്ങൾക്ക്):** ഹിന്ദി വാക്യങ്ങൾ വായിക്കാൻ ഉപകരണത്തിൽ ഹിന്ദി ശബ്ദം വേണം. Android-ൽ Settings → Text-to-speech → Google Speech Services-ൽ ഹിന്ദി ഡൗൺലോഡ് ചെയ്യൂ. Windows-ൽ Edge-ൽ "Swara (Natural)" പോലുള്ള ഹിന്ദി ശബ്ദങ്ങൾ കിട്ടും. ഹിന്ദി ശബ്ദം ഇല്ലാത്ത ഉപകരണത്തിൽ ഹിന്ദി ഭാഗം പറയില്ല (മറ്റൊരു ശബ്ദം ദേവനാഗരി തെറ്റായി വായിക്കാതിരിക്കാൻ). പാഠത്തിൽ ഒരു കുറിപ്പ് കാണും, മലയാളവും ഇംഗ്ലീഷും പതിവുപോലെ പറയും. ശബ്ദ പായ്ക്ക് ഉപയോഗത്തിലുണ്ടെങ്കിൽ (Voice source: Recorded voice, അല്ലെങ്കിൽ Automatic-ൽ ഫോണിൽ നല്ല മലയാളം ശബ്ദം ഇല്ലെങ്കിൽ) ഹിന്ദിയും അതിൽ നിന്ന് കേൾക്കാം. പായ്ക്കിൽ ഹിന്ദി വാചകങ്ങൾ ഇല്ലെങ്കിൽ, ഹിന്ദി ശബ്ദവും ഇല്ലെങ്കിൽ, ഹിന്ദി ഭാഗം പറയില്ല; പാഠത്തിൽ കുറിപ്പ് കാണും.
- ആദ്യമായി മൈക്ക് തൊടുമ്പോൾ ബ്രൗസർ അനുവാദം ചോദിക്കും. **Allow** തൊടണം.

## 4. ടീച്ചറുടെ ശബ്ദം: മലയാളം, ഇംഗ്ലീഷ്, ഹിന്ദി പെൺശബ്ദങ്ങൾ ഇതിൽ തന്നെയുണ്ട്

`voice` ഫോൾഡറിൽ ടീച്ചർ പറയുന്ന **6,253 വാചകങ്ങളും പെൺശബ്ദത്തിൽ മുൻകൂട്ടി റെക്കോർഡ് ചെയ്തു** വെച്ചിട്ടുണ്ട്: മലയാളം 2,900, ഇംഗ്ലീഷ് 2,947, ഹിന്ദി 406. ഉപകരണത്തിൽ മലയാളം ശബ്ദം ഇല്ലെങ്കിലും (ഉദാഹരണത്തിന് Windows-ലെ Chrome) ടീച്ചർ മൂന്ന് ഭാഷയിലും ഒരേ ശബ്ദത്തിൽ സംസാരിക്കും. ഒന്നും ഡൗൺലോഡ് ചെയ്യേണ്ട, ഒന്നും ഉണ്ടാക്കേണ്ട.

- **ഉപയോഗിക്കാൻ:** `voice` ഫോൾഡർ `index.html`-ന്റെ തൊട്ടടുത്ത് വെച്ചാൽ മതി; ആപ്പ് തനിയെ കണ്ടെത്തും. `index.html` ഡബിൾ ക്ലിക്ക് ചെയ്ത് തുറന്നാലും (ഫയലായി, `file://`) വെബ്‌സൈറ്റ് ആക്കിയാലും (ഭാഗം 2) ഇത് പ്രവർത്തിക്കും. വലിയവർക്കുള്ള പേജിലെ "Teacher voice" വിഭാഗത്തിൽ **"Recorded voice: ready (6,253 sentences)"** എന്ന വരി കാണണം. ഫോൾഡർ കാണുന്നില്ലെങ്കിലോ ഏതെങ്കിലും ഫയൽ ലോഡ് ആകുന്നില്ലെങ്കിലോ ആ വരി അത് പറയും; അപ്പോൾ ഉപകരണത്തിന്റെ ശബ്ദം ഉപയോഗിക്കും. ഫയലായി തുറക്കുമ്പോൾ ആദ്യമായി ഒരു വാചകം വേണ്ടിവരുമ്പോൾ അതിന്റെ ഭാഗം (10–13 MB) കമ്പ്യൂട്ടറിൽ നിന്ന് ഒരിക്കൽ ലോഡ് ചെയ്യും; ഒരു നിമിഷം എടുത്തേക്കാം, പിന്നെ വേഗത്തിലാകും.
- **എപ്പോൾ ഉപയോഗിക്കും:** വലിയവർക്കുള്ള പേജിലെ "Voice source": **Automatic** (ഉപകരണത്തിൽ സ്വാഭാവിക മലയാളം ശബ്ദം ഇല്ലെങ്കിൽ റെക്കോർഡ് ചെയ്തത്), **Recorded voice** (എപ്പോഴും), **This device** (റെക്കോർഡ് ചെയ്തത് ഉപയോഗിക്കില്ല). അതേ വിഭാഗത്തിൽ ശബ്ദത്തിന്റെ ക്രെഡിറ്റ് വരിയും കാണാം. **ശ്രദ്ധിക്കുക:** Automatic-ൽ ഫോണിൽ നല്ല മലയാളം ശബ്ദം ഉണ്ടെങ്കിൽ ആപ്പ് ഫോണിന്റെ ശബ്ദമാണ് ഉപയോഗിക്കുക (മലയാളവും ഇംഗ്ലീഷും ഹിന്ദിയും എല്ലാം). എപ്പോഴും ഈ പെൺശബ്ദം കേൾക്കണമെങ്കിൽ **Recorded voice** തിരഞ്ഞെടുക്കൂ.
- **ശബ്ദങ്ങൾ:** മലയാളം AI4Bharat-ന്റെ `vits_rasa_13` മോഡലിന്റെ MAL_F സ്പീക്കർ (ലൈസൻസ് CC BY 4.0). ഇംഗ്ലീഷ് ബ്രിട്ടീഷ് പെൺശബ്ദം `bf_isabella`, ഹിന്ദി പെൺശബ്ദം `hf_beta`, രണ്ടും Kokoro-82M മോഡലിൽ (ലൈസൻസ് Apache 2.0). രണ്ടും വാണിജ്യ ഉപയോഗത്തിനും അനുവദിക്കും, പക്ഷേ ക്രെഡിറ്റ് നിലനിർത്തണം. `voice/CREDITS.txt` ഫയൽ ഒഴിവാക്കരുത്.
- **എന്തൊക്കെ ഇതിൽ ഇല്ല:** അപ്പോൾ ഉണ്ടാക്കുന്ന വാചകങ്ങൾ (ഉദാഹരണത്തിന് ഒരു കണക്കിന്റെ ഉത്തരം, പാഠപുസ്തകത്തിലെ വരി), നിങ്ങൾ പിന്നീട് ചേർക്കുന്ന പുതിയ ഉത്തരങ്ങൾ. ഇവ ഉപകരണത്തിന്റെ ശബ്ദത്തിൽ പറയും.

**പുതിയ പാഠങ്ങളോ ഉത്തരങ്ങളോ ചേർത്താൽ:** പുതിയ വാചകങ്ങൾക്ക് മാത്രം വീണ്ടും റെക്കോർഡ് ചെയ്യാം, ഒരു സാധാരണ കമ്പ്യൂട്ടറിൽ, GPU വേണ്ട, അക്കൗണ്ട് വേണ്ട, ചെലവില്ല. വഴി `voice-tools/malayalam-female/README.txt` (മലയാളം), `voice-tools/english-hindi/README.txt` (ഇംഗ്ലീഷ്, ഹിന്ദി) എന്നിവയിൽ ഉണ്ട് (ഒരു വാചകത്തിന് ഏകദേശം ഒന്ന് മുതൽ മൂന്ന് സെക്കൻഡ്). `source/tools/make-manifest.js` പുതിയ വാചക പട്ടിക ഉണ്ടാക്കും; റെക്കോർഡ് ചെയ്ത വാചകങ്ങൾ വീണ്ടും ചെയ്യില്ല. അവസാനം `voice-tools/build_pack.py` മൂന്ന് ഭാഷയും ചേർത്ത് `voice` ഫോൾഡർ ഉണ്ടാക്കും (പഴയ രൂപം `--v2` കൊടുത്താൽ കിട്ടും; അത് `https://` വിലാസത്തിൽ മാത്രമേ പ്രവർത്തിക്കൂ).

**ശ്രദ്ധിക്കുക:**
- ശബ്ദം കേട്ട് ശരിയാണോ എന്ന് ഉറപ്പാക്കാൻ എനിക്ക് പറ്റില്ല. ഞാൻ പരിശോധിച്ചത് ഇവയാണ്: എല്ലാ 5,333 വാചകവും റെക്കോർഡ് ആയി (പിഴവ് 0), ഓരോന്നിന്റെയും ദൈർഘ്യവും ശബ്ദത്തിന്റെ പിച്ചും (പെൺശബ്ദം) നീണ്ട നിശ്ശബ്ദതയും നോക്കി, 411 വാചകങ്ങൾ യഥാർത്ഥ Chromium-ൽ ആപ്പ് എടുക്കുന്ന അതേ രീതിയിൽ എടുത്ത് പ്ലേ ചെയ്തുനോക്കി, ഇംഗ്ലീഷ്, കണക്ക്, ഹിന്ദി, മലയാളം പാഠങ്ങൾ തുറന്ന് ക്ലിപ്പുകൾ ശരിയായ ഭാഷാക്രമത്തിൽ അവസാനം വരെ പ്ലേ ആകുന്നുണ്ടെന്നും ഉപകരണത്തിന്റെ ശബ്ദത്തിലേക്ക് ഒന്നും പോകുന്നില്ലെന്നും കണ്ടു. ഉച്ചാരണം ശരിയാണോ എന്ന് ഒരു മലയാളിയുടെ ചെവി വേണം (പ്രത്യേകിച്ച് ഒറ്റ അക്ഷരങ്ങൾ: ഋ, ക്ല പോലുള്ളവ), ഹിന്ദിക്ക് ഒരു ഹിന്ദി അറിയുന്ന ആളുടെയും.
- ഇംഗ്ലീഷ് അക്ഷരങ്ങൾ ഉള്ള 12 മലയാളം വാചകങ്ങൾ (ഉദാഹരണത്തിന് "A മുതൽ Z വരെ") മലയാള അക്ഷരങ്ങളിൽ എഴുതിയാണ് റെക്കോർഡ് ചെയ്തത് ("ഏ മുതൽ സെഡ് വരെ"), ഇല്ലെങ്കിൽ ശബ്ദത്തിന് ആ അക്ഷരങ്ങൾ അറിയില്ല. ഇംഗ്ലീഷ് ശബ്ദം വലിയ അക്ഷരങ്ങളെ അക്ഷരത്തിന്റെ പേരായും അക്കങ്ങളെ സംഖ്യയായും വായിക്കും.
- ഇംഗ്ലീഷ് വാക്യങ്ങളിൽ ചിലത് വേഗത്തിലാണ് പറയുന്നത് (ഒരു സെക്കൻഡിൽ നാലിലേറെ വാക്ക്). ആപ്പിലെ വേഗത നിയന്ത്രണം ("പതുക്കെ" ബട്ടൺ) ഉപയോഗിക്കാം.
- ഫോണിൽ ഓരോ വാചകവും എത്ര വേഗം കേൾക്കാം എന്ന് ഞാൻ അളന്നിട്ടില്ല. ഒരു വാചകം ശരാശരി 9 KB ആണ് (ഏറ്റവും നീണ്ടതിന് ഏകദേശം 45 KB), അതുകൊണ്ട് സാധാരണ ഇന്റർനെറ്റിൽ വേഗം കിട്ടേണ്ടതാണ്.
- ഈ ശബ്ദങ്ങൾ ഇഷ്ടമായില്ലെങ്കിൽ `voice` ഫോൾഡർ ഒഴിവാക്കിയാൽ മതി, ആപ്പ് ഉപകരണത്തിന്റെ ശബ്ദത്തിലേക്ക് മടങ്ങും.

പഴയ Colab നോട്ട്ബുക്ക് (`voice-tools/kunju-voice-pack.ipynb`, Indic Parler-TTS, Hugging Face അക്കൗണ്ടും GPU-വും വേണം) ഇപ്പോഴും ഉണ്ട്, പക്ഷേ അത് മലയാളം ഉൾപ്പെടെ **മുഴുവൻ `voice` ഫോൾഡറും** മാറ്റിയെഴുതും. അതായത് ഈ പെൺശബ്ദങ്ങൾ പോകും. അത് ഉപയോഗിക്കുന്നെങ്കിൽ മാത്രം, ഫോൾഡർ മാറ്റും മുൻപ് `voice` ഫോൾഡർ പകർത്തി സൂക്ഷിക്കൂ.

## 5. സ്വന്തം പാഠപുസ്തകം ചേർക്കാം

വലിയവർക്കുള്ള പേജിൽ **How should Kunju Teacher teach? → My textbooks** തിരഞ്ഞെടുത്ത് `.txt` ഫയൽ ചേർക്കൂ. കുട്ടി ചോദിക്കുമ്പോൾ ടീച്ചർ ആദ്യം സ്വന്തം ഉത്തരങ്ങൾ നോക്കും, ഇല്ലെങ്കിൽ ഈ പുസ്തകത്തിൽ നിന്ന് ഏറ്റവും യോജിച്ച വാചകം കണ്ടെത്തി "നമ്മുടെ പുസ്തകത്തിൽ ഇങ്ങനെ പറയുന്നു" എന്ന് പറയും. PDF-നെ ടെക്സ്റ്റ് ആക്കാൻ: Google Drive-ൽ PDF അപ്‌ലോഡ് ചെയ്ത് "Open with Google Docs" ചെയ്ത ശേഷം File → Download → Plain text (.txt). ഇതിന്റെ തിരയൽ വാക്കുകൾ ഒത്തുനോക്കുന്ന രീതിയാണ്; പുസ്തകം വായിച്ച് മനസ്സിലാക്കി ഉത്തരം ഉണ്ടാക്കില്ല.

## 6. ടീച്ചർക്ക് അറിയാത്ത ചോദ്യങ്ങൾ: ഉത്തരങ്ങൾ കൂട്ടാം

കുട്ടി ഒരു ചോദ്യം ചോദിക്കുകയും ടീച്ചർക്ക് ഉത്തരം ഇല്ലാതിരിക്കുകയും ചെയ്താൽ, ആ ചോദ്യം ആ ഉപകരണത്തിൽ മാത്രം ഓർത്തുവെക്കും (ഒരിടത്തേക്കും അയക്കില്ല).

1. വലിയവർക്കുള്ള പേജിൽ **Questions the teacher could not answer** കാണാം. **Copy the list** അമർത്തൂ.
2. Claude-ൽ ഒട്ടിച്ച് ഇങ്ങനെ പറയൂ: "ഈ ചോദ്യങ്ങൾക്ക് കുഞ്ഞു ടീച്ചറിന്റെ ഉത്തരങ്ങളിൽ ഉത്തരം ചേർക്കൂ", `source/` ഫോൾഡറും (ZIP ആക്കി) കൊടുക്കൂ.
3. പുതിയ `index.html` കിട്ടും. അത് GitHub-ൽ പഴയതിനു പകരം അപ്‌ലോഡ് ചെയ്താൽ മതി.

ഇങ്ങനെ ഓരോ ആഴ്ചയും ടീച്ചർ കൂടുതൽ അറിവുള്ളതാകും, ചെലവില്ലാതെ.

## 7. സത്യസന്ധമായ പരിമിതികൾ

- ഉത്തരങ്ങൾ ഞാൻ (Claude) എഴുതിയതാണ്, അവ ഒരു മലയാളം അധ്യാപിക വായിച്ച് ശരിയാണെന്ന് ഉറപ്പാക്കിയിട്ടില്ല. കുട്ടികൾക്ക് കൊടുക്കും മുൻപ് ഒരു അധ്യാപകരെക്കൊണ്ടോ വീട്ടിലെ വലിയവരെക്കൊണ്ടോ ഒരു തവണ വായിപ്പിക്കൂ. മലയാളം ഭാഷയിലും വസ്തുതകളിലും തെറ്റ് കണ്ടാൽ എന്നോട് പറഞ്ഞാൽ തിരുത്താം.
- ടീച്ചർക്ക് ഇപ്പോൾ 109 വിഷയങ്ങളേ അറിയൂ. ഇതിൽ ഇല്ലാത്ത ചോദ്യത്തിന് "അറിയില്ല" എന്ന് പറയും. ഇത് ഒരു ChatGPT പോലെ ഏത് ചോദ്യത്തിനും മറുപടി പറയുന്ന ആപ്പ് അല്ല. അതിന് പണവും, കുട്ടികളുടെ ആപ്പിനെ അനുവദിക്കുന്ന AI സേവനവും വേണം.
- പാഠങ്ങൾ ക്ലാസ് 1 മാത്രം, 4 കളി. വലിയവർക്കുള്ള പേജിൽ **Board** മാറ്റിയാൽ പാഠങ്ങൾ മാറും: Kerala-യ്ക്ക് 29 പാഠം, CBSE-ക്ക് 87 പാഠം (ഹിന്ദി 29 പാഠം ഉൾപ്പെടെ: 10 അക്ഷരമാല പാഠവും 19 സാരംഗി അധ്യായവും; ഹിന്ദി കട്ട CBSE ബോർഡിൽ മാത്രം).
  - **മലയാളം അക്ഷരമാല മുഴുവൻ** രണ്ട് ബോർഡിലും ഉണ്ട്: 13 പാഠം, 56 അക്ഷരം (സ്വരങ്ങൾ, അം, അഃ, വ്യഞ്ജനങ്ങൾ, ചില്ലക്ഷരങ്ങൾ). ഓരോ അക്ഷരത്തിനും ഒരു ചിത്രവും വാക്കും ഉണ്ട്.
  - ഖ, ഘ, ഛ, ഝ, ഢ, ഋ പോലെ വാക്ക് തുടങ്ങാത്തതോ അപൂർവമോ ആയ അക്ഷരങ്ങൾക്ക് (ഖഗം, ഛത്രം, ഝഷം, ഢക്ക, ഋഷി) ഒരു അധ്യാപിക വാക്ക് ശരിയാണോ എന്ന് നോക്കണം. ങ, ഠ, ണ, ഥ, ള, ഴ എന്നിവ പഠിപ്പിക്കുന്നത് ആ അക്ഷരം ഉള്ളിലുള്ള വാക്ക് (തെങ്ങ്, പാഠം, മണി, കഥ, വെള്ളം, മഴ) കൊണ്ടാണ്.
  - **കൂട്ടക്ഷരങ്ങൾ:** അക്ഷരമാലയ്ക്ക് ശേഷം 6 പാഠം, 30 കൂട്ടക്ഷരം (ക്ക, ച്ച, ട്ട, ത്ത, പ്പ, മ്മ, ല്ല, ള്ള, ണ്ണ, ന്ന, റ്റ, ങ്ക, ഞ്ച, ണ്ട, ന്ത, മ്പ, ഞ്ഞ, ങ്ങ, ക്ഷ, ത്ര, സ്ക, സ്ത, സ്പ, പ്ര, ക്ര, ബ്ര, ട്ര, ഗ്ല, ക്ല, ദ്ര). ഓരോന്നിനും ഒരു വാക്കും ചിത്രവും ഉണ്ട്. ന്റ, വ്വ, യ്യ എന്നിവ ഇല്ല.
  - ഈ പട്ടിക SCERT പുസ്തകത്തിലെ ക്രമവുമായി ഒത്തുനോക്കിയിട്ടില്ല. അവസാനത്തെ പാഠത്തിലെ വാക്കുകൾ (ബ്രെഡ്, ട്രെയിൻ, ഗ്ലാസ്, ക്ലോക്ക്) ഇംഗ്ലീഷിൽ നിന്ന് വന്നതാണ്, ഒന്നാം ക്ലാസ്സിൽ പഠിപ്പിക്കുമോ എന്ന് അധ്യാപിക പറയണം.
  - CBSE പാഠങ്ങൾ NCERT പുസ്തകങ്ങളായ Mridang (ഇംഗ്ലീഷ്), Joyful Mathematics (കണക്ക്) എന്നിവയുടെ വിഷയക്രമത്തിലാണ്. കണക്കിൽ 13 അധ്യായവും ഇംഗ്ലീഷിൽ 4 യൂണിറ്റും ഉണ്ട്.
  - പുസ്തകത്തിലെ കഥകളും കവിതകളും അതേപടി ഇല്ല. അതേ വിഷയങ്ങൾ എന്റെ സ്വന്തം വാക്കുകളിൽ പഠിപ്പിക്കുന്നു.
  - NCERT-യുടെ പാഠ ലിസ്റ്റ് മൂന്നാം കക്ഷി വെബ്സൈറ്റുകളിൽ നിന്ന് എടുത്തതാണ്, യഥാർത്ഥ പുസ്തകവുമായി ഒത്തുനോക്കിയിട്ടില്ല. സ്കൂളിൽ പഴയ പുസ്തകങ്ങൾ (Marigold, Math Magic) ആണെങ്കിൽ ക്രമം വ്യത്യസ്തമായിരിക്കും.
  - **ഹിന്ദി അക്ഷരമാല (CBSE):** 10 പാഠം, 49 അക്ഷരം (13 സ്വരം, 33 വ്യഞ്ജനം, 3 സംയുക്താക്ഷരം क्ष त्र ज्ञ). ഓരോ അക്ഷരത്തിനും ദേവനാഗരി വാക്ക്, ചിത്രം, മലയാള അക്ഷരത്തിൽ ഉച്ചാരണം, മലയാളത്തിലും ഇംഗ്ലീഷിലും അർത്ഥം. ടീച്ചർ ആദ്യം ഹിന്ദിയിൽ പറയും ("आ से आम"), പിന്നെ മലയാളത്തിലും ഇംഗ്ലീഷിലും. ङ ञ ण ष क्ष ज्ञ അः എന്നീ അക്ഷരങ്ങളിൽ വാക്ക് തുടങ്ങാത്തതിനാൽ "ഈ അക്ഷരം ഉള്ള വാക്കിന്റെ ചിത്രം" എന്ന ചോദ്യമാണ്.
  - ഹിന്ദി വാക്കുകളും മലയാള അക്ഷരത്തിലെ ഉച്ചാരണവും ഒരു ഹിന്ദി അറിയുന്ന ആൾ നോക്കണം. പ്രത്യേകിച്ച് रङ्ग, पञ्च, पुष्प, दुःख, विज्ञान പോലുള്ള വാക്കുകൾ (പരമ്പരാഗത എഴുത്ത്), ഖ ഘ ഛ ഝ ഠ ഢ ഫ പോലുള്ള ശബ്ദങ്ങളുടെ മലയാള എഴുത്ത് ഏകദേശമാണ്. യഥാർത്ഥ ഉച്ചാരണം ഹിന്ദി ശബ്ദമാണ്, ഞാൻ അത് കേട്ടിട്ടില്ല.
  - **ഹിന്ദി സാരംഗി പുസ്തകം (CBSE, सारंगी - भाग 1):** നിങ്ങൾ നൽകിയ 19 അധ്യായങ്ങളുടെ PDF അടിസ്ഥാനമാക്കി 1 മുതൽ 19 വരെയുള്ള അധ്യായങ്ങൾ ഒരൊറ്റ ലിസ്റ്റായി ചേർത്തിട്ടുണ്ട്. ഓരോ അധ്യായത്തിലും 2 കഥ/കവിത കാർഡുകൾ, 3 ഹിന്ദി വാക്കുകൾ, നോട്ടുബുക്കും പെൻസിലും എടുത്ത് അക്ഷരങ്ങളും മാത്രകളും (ा ि ी ु ू े ै ो ौ) ചേർത്ത് എഴുതാനുള്ള 1 നോട്ടുബുക്ക് ആക്ടിവിറ്റി കാർഡ്, 4 ക്വിസ് ചോദ്യങ്ങൾ എന്നിവയുണ്ട്. പുസ്തകത്തിലെ വാചകങ്ങൾ പകർത്താതെ സ്വന്തം വാക്കുകളിലാണ് കഥകൾ എഴുതിയിരിക്കുന്നത്.
  - ഹിന്ദി പാഠത്തിലെ "പറയൂ" മൈക്ക് ഹിന്ദിയിൽ (hi-IN) കേൾക്കും. ദേവനാഗരി വാക്കും മലയാള/ഇംഗ്ലീഷ് അർത്ഥവും ഉച്ചാരണവും സ്വീകരിക്കും. ദേവനാഗരിയുടെ പഴയ എഴുത്തും ഇന്നത്തെ എഴുത്തും ഒരുപോലെ എടുക്കും (रङ्ग / रंग, झण्डा / झंडा, ऊँट / ऊंट, दुःख / दुख), नुक्ता ഉണ്ടെങ്കിലും ഇല്ലെങ്കിലും. പക്ഷേ ബ്രൗസർ ഇംഗ്ലീഷ് വാക്ക് ("mango") ദേവനാഗരിയിൽ ("मैंगो") എഴുതിയേക്കാം, അപ്പോൾ ശരിയായി മനസ്സിലാക്കില്ല. ഹിന്ദി വാക്ക് പറയുക, അല്ലെങ്കിൽ ചിത്രം തൊടുക.
  - 11 മുതൽ 99 വരെയുള്ള സംഖ്യകളുടെ മലയാളം പേരുകൾ ഒരു അധ്യാപിക നോക്കണം.
- മൈക്ക് തിരിച്ചറിയൽ ബ്രൗസറിന്റെ സേവനമാണ്. കുട്ടികളുടെ സ്വരം, ഫോൺ, ശബ്ദ ബഹളം എന്നിവ അനുസരിച്ച് ചിലപ്പോൾ തെറ്റായി കേൾക്കും. അപ്പോൾ "തൊട്ട് ചോദിക്കാവുന്ന ചോദ്യങ്ങൾ" ഉപയോഗിക്കാം.

## 8. സ്വകാര്യത

പുരോഗതി, അപ്‌ലോഡ് ചെയ്ത പുസ്തകം, കുട്ടിയുടെ ചോദ്യങ്ങൾ എല്ലാം ആ ഉപകരണത്തിൽ മാത്രം. ടീച്ചറുടെ ഉത്തരം ഒരു AI സേവനത്തിലേക്കും ചോദ്യം അയച്ച് വരുന്നതല്ല. റെക്കോർഡിങ് സൂക്ഷിക്കില്ല. മൈക്ക് ഉപയോഗിക്കുമ്പോൾ ബ്രൗസർ (ഉദാഹരണത്തിന് Chrome) ശബ്ദം തിരിച്ചറിയാൻ അതിന്റെ സ്വന്തം സേവനത്തിലേക്ക് അയച്ചേക്കാം. അത് ബ്രൗസറിന്റെ ഭാഗമാണ്, ഈ ആപ്പിന്റേതല്ല. കുട്ടികളോട് പേരോ വിലാസമോ ഫോൺ നമ്പറോ ചോദിക്കില്ല.

## ഈ ഫോൾഡറിൽ

- `index.html`: ആപ്പ്. ഇത് മാത്രം മതി പ്രവർത്തിക്കാൻ.
- `.nojekyll`: GitHub Pages-ന് വേണ്ടി (ഒഴിഞ്ഞ ഫയൽ).
- `voice/`: റെക്കോർഡ് ചെയ്ത മലയാളം, ഇംഗ്ലീഷ്, ഹിന്ദി പെൺശബ്ദങ്ങൾ (`index.js`, `pack-0.js` മുതൽ `pack-5.js` വരെ; ഓരോ ഫയലും 14 MB-ൽ താഴെ) കൂടെ `CREDITS.txt` (ലൈസൻസ് ക്രെഡിറ്റ്, ഒഴിവാക്കരുത്).
- `voice-tools/`: `malayalam-female/` (മലയാളം ശബ്ദം ഉണ്ടാക്കിയ സ്ക്രിപ്റ്റുകൾ), `english-hindi/` (ഇംഗ്ലീഷ്, ഹിന്ദി ശബ്ദം ഉണ്ടാക്കിയ സ്ക്രിപ്റ്റുകൾ), `build_pack.py` (മൂന്നും ചേർത്ത് `voice` ഫോൾഡർ ഉണ്ടാക്കും; പുതിയ വാചകങ്ങൾ ചേർക്കാൻ), വാചകങ്ങളുടെ പട്ടിക, പഴയ Colab നോട്ട്ബുക്ക്.
- `source/`: ആപ്പിന്റെ സോഴ്സ് കോഡും ടെസ്റ്റുകളും (ഉത്തരങ്ങൾ കൂട്ടുമ്പോൾ Claude-ന് കൊടുക്കാൻ).
