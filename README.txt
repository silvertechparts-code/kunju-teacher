This folder holds the recorded teacher voices (female): Malayalam, English and Hindi.

  index.js     the list of sentences and where each one sits (also holds the credit line the app shows)
  pack-0.js ... pack-N.js   the recordings (each file is text; the page reads one sentence at a time where the host allows it)
  CREDITS.txt  who made the voices and under which licences (CC BY 4.0 and Apache 2.0). Keep this file.

Keep this folder next to index.html. It works when index.html is opened by double-clicking (as a file) and when the
folder is put on a web address (see README-ml.md, part 2). Grown-ups page > Teacher voice shows "Recorded voice: ready"
when the app has found it.
The pack covers every fixed Malayalam, English and Hindi sentence in the app. Sums made up on the spot, new answers,
and a few Malayalam words filed under English are spoken by the device's own voice.
